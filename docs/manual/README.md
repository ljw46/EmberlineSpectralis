# Emberline Spectralis - the manual

Welcome! This is a wavetable synth built for melodic, deep and organic house: warm pads, rolling bass, glassy plucks
and the odd stutter-y lead. You don't need to know synth theory to get going. If you can turn a knob, you're sorted.

**Start here:**

1. [Getting started](01-getting-started.md) - install it, make a sound, find your way around

4. [Moving things around](04-modulation.md) - LFOs, envelopes, macros and how to hook them up
5. [Effects](05-effects.md) - distortion, chorus, delay, reverb
6. [Arp and stutter](06-arp-and-stutter.md) - the arpeggiator and the speed-up/slow-down roll

10. [Troubleshooting](10-troubleshooting.md) - when something's not right
11. [Knob reference](reference.md) - every control, its range and default
